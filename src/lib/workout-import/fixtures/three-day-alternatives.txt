
Sample Workout Structure (60–75 minutes per session):

• Day 1: Full Body A (Quad/Push Focus)
	• Barbell or Goblet Squat: 3 sets x 6–10 reps
	• Incline Dumbbell Bench Press: 3 sets x 8–12 reps
	• Seated Cable Row or Barbell Row: 3 sets x 8–12 reps
	• Romanian Deadlift: 3 sets x 8–12 reps
	• Dumbbell Lateral Raises: 3 sets x 12–15 reps
	• Plank or Core exercise: 3 sets x 30–60 seconds
• Day 2: Full Body B (Hinge/Pull Focus)
	• Romanian Deadlift or Trap Bar Deadlift: 3 sets x 6–8 reps
	• Overhead Barbell or Dumbbell Press: 3 sets x 8–12 reps
	• Lat Pulldown or Pull-ups: 3 sets x 8–12 reps
	• Leg Press or Bulgarian Split Squats: 3 sets x 8–12 reps
	• Bicep Curls & Tricep Pushdowns (Superset): 3 sets x 10–15 reps
	• Hanging Leg Raises: 3 sets x 10–15 reps
• Day 3: Full Body C (Power & Accessory Focus)
	• Front Squat or Leg Press: 3 sets x 8–12 reps
	• Flat Dumbbell Bench Press or Push-ups: 3 sets x 8–12 reps
	• Chest-Supported Row: 3 sets x 8–12 reps
	• Leg Curls: 3 sets x 10–15 reps
	• Calf Raises: 3 sets x 15 reps
	• Face Pulls (Rear Delts/Posture): 3 sets x 12–15 reps
